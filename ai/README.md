# AI workspace

This is the canonical home for Water-Intel's agent and MCP surfaces.

- `agents\` holds agent-specific prompts, instructions, skills, hooks, workflows, evals, and context.
- `mcp\` holds MCP server/client code, reusable resources, and tool schemas.

The current dashboard remains in `web\app\` as a transitional runtime path, but new AI-facing assets should be added under `ai\`.
