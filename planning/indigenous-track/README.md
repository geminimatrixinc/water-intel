## Why this track exists

The Government of Canada mandates a **minimum 5% of all federal contract value** go to
Indigenous businesses (96 departments, fully in force). Ontario, its crown corporations
(Hydro One, OPG, IESO, Metrolinx), and many municipalities run parallel Indigenous
procurement programs. The Indigenous supplier pool is **thin on modern AI/ML capability** —
that is the gap Gemini Matrix fills.

**Unfair advantage stack (rare to have all five):**
1. Mohawk status + 100%-owned, already-registered corporation
2. 20 years IT delivery experience
3. Modern AI / agent / MCP fluency (almost no IBD-listed firm ships this)
4. A working codebase (Water-Intel) as a live proof point
5. Direct fit with a *named federal priority* (First Nations drinking water)

## How to use this track

1. Work **top-to-bottom, one phase at a time.** Don't jump ahead.
2. Each phase file lists tasks by week with checkboxes, time estimates, and a
   "Done when" acceptance line. Check boxes as you go.
3. **One momentum rule:** finish at least ONE checkbox every week, even a small one.
   Consistency beats intensity on a part-time schedule.
4. Reference docs (`targets_and_contacts.md`, `grants_and_funding.md`) are lookups —
   read them when a task points you there, don't try to consume them all at once.
